# Dicionário de dados

Legenda: **P** = dado potencialmente pessoal; **N** = não pessoal. Relações e timestamps seguem os nomes técnicos do schema.

| Model                             | Campo(s)                                                                    |               Tipo |           Obrigatório           | Descrição/regra                                                      | Classe |
| --------------------------------- | --------------------------------------------------------------------------- | -----------------: | :-----------------------------: | -------------------------------------------------------------------- | :----: |
| Organization                      | legalName, tradeName, document, email, phone                                |             String |            legalName            | raiz multi-organização; documento único quando presente              |   N    |
| Hospital / Supplier               | organizationId, legalName, internalCode, document, active                   |     String/Boolean |         novos registros         | códigos e documentos únicos por organização; desativação lógica      |   N    |
| HospitalAddress / SupplierAddress | street, number, district, city, state, postalCode, country                  |             String |               sim               | endereço normalizado; `primary` indica preferência                   |   N    |
| Insurance                         | organizationId, name, code, document                                        |             String |         novos registros         | código/documento únicos por organização                              |   N    |
| HospitalInsurance                 | hospitalId, insuranceId                                                     |                 FK |               sim               | par único                                                            |   N    |
| Manufacturer / Brand              | organizationId/manufacturerId, name                                         |          FK/String |               sim               | fabricante é independente do fornecedor                              |   N    |
| MaterialCategory                  | organizationId, parentId, name                                              |          FK/String |         parent opcional         | árvore por autorrelação                                              |   N    |
| Material                          | internalCode, categoryId, brandId, unitOfMeasure, ANVISA                    |           diversos |         código/unidade          | cadastro técnico; categoria exigida pela camada de entrada           |   N    |
| SupplierMaterial                  | purchasePrice, currency, validFrom, validUntil                              |  Decimal/Enum/Date |               sim               | preço não negativo e vigência crescente; histórico append-only       |   N    |
| EmailMessage                      | sender, recipients, subject, bodies, metadata                               |        String/Json |            cabeçalho            | conteúdo pode conter dado pessoal; provider ID único por organização |   P    |
| EmailAttachment                   | filename, mimeType, size, storageKey                                        |         String/Int |            metadados            | sem binário no banco                                                 |   P    |
| QuotationRequest                  | patientReference, requestingDoctor, hospitalId, insuranceId, urgency/status |           diversos | referência e vínculos opcionais | referência do paciente deve ser pseudonimizada                       |   P    |
| QuotationItem                     | requestedDescription, quantity, confidence, status                          | String/Int/Decimal |      descrição/quantidade       | confiança entre 0 e 1; sem execução de IA                            |   P    |
| QuotationProposal                 | totais, margens, versão, aprovadores                                        |         Decimal/FK |               sim               | persistência sem cálculo; versão única por solicitação               |   P    |
| QuotationProposalItem             | custos, preços, margem                                                      |            Decimal |               sim               | não negativos; nenhuma regra financeira executada                    |   N    |
| StatusHistory                     | previousStatus, newStatus, changedBy, reason, metadata                      |          Enum/Json |           novo status           | imutável e sem `updatedAt`                                           |   P    |
| AuditLog                          | before, after, metadata, IP, userAgent                                      |        Json/String |          ação/entidade          | nunca armazenar tokens, cookies ou segredos                          |   P    |
